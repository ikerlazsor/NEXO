# 012 — Confirmar 120fps en iPhones ProMotion

- **Status**: TODO
- **Commit**: bc6f0c7
- **Severity**: LOW (oportunidad)
- **Category**: Performance
- **Estimated scope**: 1 línea en `app.json`. **Necesita build nativa nueva; no se publica con `eas update`.**

## Problem

En iPhones con pantalla ProMotion, las animaciones de librerías (Reanimated incluida) se limitan a 60fps salvo que el `Info.plist` tenga `CADisableMinimumFrameDurationOnPhone = true`. En el repo no aparece:

```json
// app.json:37-45 — infoPlist actual (no incluye la clave)
"infoPlist": {
  "CFBundleDisplayName": "Nexo",
  "NSLocationWhenInUseUsageDescription": "…",
  "NSMicrophoneUsageDescription": "…",
  "ITSAppUsesNonExemptEncryption": false,
  "UIBackgroundModes": ["remote-notification"]
}
```

`app.config.js` tampoco la añade. Las versiones recientes de Expo suelen ponerla por defecto en el prebuild, pero no está garantizado: hay que comprobarlo y, si falta, añadirla.

## Target

```json
"infoPlist": {
  "CFBundleDisplayName": "Nexo",
  "CADisableMinimumFrameDurationOnPhone": true,
  …
}
```

## Steps

1. Comprueba qué genera el prebuild sin tocar nada: `npx expo prebuild --platform ios --no-install` en una **copia** del repo o en un worktree, y busca la clave en `ios/<App>/Info.plist`. Borra la carpeta `ios/` generada después (el repo no la versiona).
2. Si la clave ya está con `<true/>`: marca este plan como DONE sin cambios y anótalo.
3. Si no está: añade `"CADisableMinimumFrameDurationOnPhone": true` dentro de `expo.ios.infoPlist` en `app.json`, justo después de `CFBundleDisplayName`.

## Boundaries

- NO cambies ninguna otra clave de `app.json`.
- NO añadas la carpeta `ios/` al repo.
- NO publiques con `eas update`: la clave solo llega con un binario nuevo.

## Verification

- **Mechanical**: `npx expo config --type introspect` muestra `CADisableMinimumFrameDurationOnPhone: true` en `ios.infoPlist`.
- **Feel check** en un iPhone Pro (13 Pro o posterior) con build nueva:
  - Activar Ajustes › Desarrollador › "Mostrar velocidad de fotogramas" si está disponible, o comparar a ojo: el arrastre del panel de filtros y el deslizamiento para responder se ven más fluidos que en la build anterior.
- **Done when**: el `Info.plist` generado contiene la clave a `true`.
